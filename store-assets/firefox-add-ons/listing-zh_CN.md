## 详细说明

<!-- 粘贴此行以下、下一个标题之前的全部内容。 -->

别再猜 AI 套餐还剩多少。AI Limits 在一个 Firefox 侧边栏中显示你的 AI 订阅和 API 账户的用量限额：还剩多少、何时重置、当前节奏是否过快，让你不会在工作到一半时突然撞上限额。

为什么选择 AI Limits
• 所有套餐，一个面板：聊天订阅、编程助手、API 余额和自建网关并排显示，不用再挨个打开账户页面。
• 已用或剩余：所有用量条都可以在“已用”和“剩余”之间切换，并显示服务提供的套餐名称。
• 重置倒计时：在服务提供重置时间时，查看每个用量周期何时恢复，决定是等一等、放慢节奏，还是换个工具。
• 用量节奏：对于同时具备可靠重置时间、以及起始时间或周期时长其中之一的用量周期，AI Limits 会比较已用配额与已经过去的时间，提前提醒你是否会在重置前用完。
• 用量历史：打开任一用量周期，即可查看用量的上升与重置，最多在本地保留 30 天。预付费余额同样绘制成图，并标出充值。
• 按你的习惯排列：拖动调整服务顺序，或在不断开连接的情况下隐藏某个服务。隐藏的服务仍保持连接并继续刷新。
• 大多数服务在后台约每 15 分钟自动刷新一次，关闭侧边栏也不受影响。
• 支持简体中文和英文。侧边栏默认跟随 Firefox 语言，也可以在设置中固定。

支持 23 个服务
AI Limits 支持 23 个 AI 服务，涵盖聊天与编程订阅、按额度或余额计费的 API 平台，以及自建 API 网关。只连接你在用的服务；每项连接都需要主动启用，并且只获得你为它批准的 Firefox 访问权限。订阅类服务使用你已在 Firefox 中登录的账号；API 类服务通过引导流程使用你自行提供的密钥。

查看全部支持的服务，以及 AI Limits 为每个服务显示的内容：
https://get-ai-limits.com/zh-CN/providers/

发送什么、发送到哪里
• 请求只发送到你连接的服务。某个服务的登录状态或 API 密钥只会发送给该服务本身，用于获取套餐、用量和余额数据。因此 Firefox 在安装时会请你允许发送身份验证信息。
• 数据保存在本地：你的用量历史只留在你自己的设备上，不会发送给开发者或任何其他人。AI Limits 绝不读取你的提示词或对话。
• 没有广告，无需注册 AI Limits 账号，也没有任何分析或遥测。
• 免费，并以 MIT 许可证开源：https://get-ai-limits.com/source/

问题反馈、错误报告或申请支持新服务：https://get-ai-limits.com/support/

AI Limits 是 TiantianFlow 独立开发的项目，与任何已连接的服务提供商及其母公司或关联公司均无关联，也未获得它们的认可或授权。
